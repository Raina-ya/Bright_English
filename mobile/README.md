# Bright English Mobile

Expo SDK 54 phone UI skeleton with SafeAreaView, 44px controls, bottom navigation, KeyboardAvoidingView, AsyncStorage, and Expo Speech.

On a normal Windows terminal from this `mobile` folder:

```powershell
npm.cmd install
npx expo install --fix
npx expo start --tunnel
```

Scan the QR code in Expo Go. LAN address of the development PC is `10.235.217.48`; use tunnel if LAN connection fails.
